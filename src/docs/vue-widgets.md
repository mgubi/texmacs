# Vue widgets

All widget constructors declared in `src/Graphics/Gui/widget.hpp` are
implemented in `src/Plugins/Vue/vue_widget.cpp`. Two kinds of classes:

* **`vue_ui_rep`**, the "umbrella" widget: the constructor functions are
  generated by the `VUE_WIDGET(name, type, field, ...)` macro, which defines a
  `struct vue_<name>` holding the arguments (a blackbox), and
  `vue_ui_rep::do_layout ()` dispatches on the `type` string. Widgets which
  need extra state are converted in the `vue_ui_rep` constructor into a
  "star" struct (`vue_tabs_widget_star`, `vue_enum_widget_star`,
  `vue_cached_pull_button`...). State is read with `open_box`, modified and
  written back with `close_box` at the end of `do_layout`.
* **dedicated classes** for widgets with a richer protocol:
  `vue_simple_widget_rep` (editors, `simple_widget_rep`),
  `vue_texmacs_widget_rep` (main window), `vue_plain_window_widget_rep`
  (windows), `vue_input_text_widget_rep`, `vue_inputs_list_widget_rep`
  + `vue_field_widget_rep` (dialogs), `vue_chooser_widget_rep` (native file
  dialog), `vue_tree_view_widget_rep`, `vue_ink_widget_rep`.

Callbacks are never run during layout: widgets queue a `command` in
`cmd_list` (usually an `applied_command (cmd, object args)`), executed by the
event loop after the layout pass. `noop_command ()` is a valid do-nothing
command (a nil command must never be invoked).

## Styles (`WIDGET_STYLE_*`)

| Flag | Effect |
|---|---|
| `MINI` | smaller font (`get_default_font`), smaller check box |
| `MONOSPACED` | typewriter font |
| `GREY`, `INERT` | greyed text; inert widgets take no input |
| `PRESSED` | darker flat button (toggled tool bar buttons) |
| `BUTTON` | framed push button |
| `CENTERED` | text centered in its container |
| `BOLD` | bold font |

`context_style` adds flags from enclosing divisions (bold titles, grey
discrete texts).

## Tool areas of the main window

`edit_interface_rep::resume ()` installs `(dynamic (texmacs-side-tools win))`
etc. through `SLOT_SIDE_TOOLS`, `SLOT_LEFT_TOOLS`, `SLOT_BOTTOM_TOOLS`,
`SLOT_EXTRA_TOOLS`; Scheme shows/hides them with `show-side-tools` /
`show-bottom-tools` (`SLOT_*_VISIBILITY`). `layout_tool_panel` lays them out
as scrollable framed panels (side panels at most 40% of the width, bottom rows
at most 40% of the height). A tool is `(division "title" (hlist (text name)
>> (division "plain" ("x" close))))` followed by its body (`tm-tool` macro in
`kernel/gui/menu-widget.scm`). A side holds one tool per position
(`:right`, `:transient-right`, `:bottom-right`, ...): `tool-select` replaces
the tool of its position, and `texmacs-side-tools` stacks the top ones, a
growing glue and the bottom ones. `section-tabs` (`menu-define.scm`) is a
`refreshable` whose tabs are plain menu buttons, the active one wrapped in
`(class "section-active-tab" ...)`.
