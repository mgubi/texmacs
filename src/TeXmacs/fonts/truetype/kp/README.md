# Kp Fonts

KpMath regular and bold with the KpRoman text faces, KpMath-Sans and
KpMath-SansBold with the KpSans text faces, and KpMono; the OpenType
version of the Kp Fonts.

Upstream: https://ctan.org/pkg/kpfonts-otf
