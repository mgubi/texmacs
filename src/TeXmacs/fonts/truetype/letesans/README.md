# Lete Sans Math

LeteSansMath.otf and LeteSansMath-Bold.otf, a sans serif math font in the
style of Lato, with its own letters, so that it needs no text font.

Upstream: https://ctan.org/pkg/lete-sans-math
License: SIL Open Font License 1.1, see OFL.txt

These fonts are used by the math font profiles in
`TeXmacs/progs/fonts/fonts-opentype.scm`; see
`doc/opentype-math-fonts-survey.md`.
