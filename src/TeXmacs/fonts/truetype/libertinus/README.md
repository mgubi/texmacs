# Libertinus

LibertinusMath-Regular.otf and the Libertinus Serif, Sans and Mono text
faces; the maintained successor of Linux Libertine and Linux Biolinum,
which are still shipped in `../libertine`. Upstream has no Sans Bold Italic.

Upstream: https://github.com/alerque/libertinus
