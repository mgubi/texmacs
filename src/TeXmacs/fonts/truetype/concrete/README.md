# Concrete

Concrete-Math.otf and Concrete-Math-Bold.otf, the OpenType math font for
Knuth's Concrete Roman, and the four Concrete faces of CM Unicode
(cmunorm, cmunoti, cmunobx, cmunobi) as its text companion.

Upstream: https://ctan.org/pkg/concmath-otf and https://cm-unicode.sourceforge.io
License: SIL Open Font License 1.1, see OFL.txt (CM Unicode; Concrete Math is under
the same license)
