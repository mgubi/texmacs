# Fira

FiraSans and FiraMono text faces, and FiraMath-Regular.otf, the sans serif
math font for Fira Sans. Upstream has released only the Regular weight of
Fira Math; the monospaced faces have no italics.

Upstream: https://github.com/firamath/firamath and
https://github.com/mozilla/Fira
