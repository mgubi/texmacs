# Antykwa Torunska

Twelve faces of Antykwa Torunska: regular, bold and light, each also
condensed (the medium weight is left out: the font selection of TeXmacs
takes a medium face for the regular one).

Upstream: https://jmn.pl/en/antykwa-torunska/ and https://ctan.org/pkg/antt
