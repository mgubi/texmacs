# TeX Gyre

The TeX Gyre text fonts (Adventor, Bonum, Chorus, Cursor, Heros, Pagella,
Schola, Termes) and math fonts, by the GUST e-foundry (B. Jackowski,
J. M. Nowacki, P. Strzelczyk), as in TeX Live (`fonts/tex-gyre`,
`fonts/tex-gyre-math`).
