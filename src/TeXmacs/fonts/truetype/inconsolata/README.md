# Inconsolata

Inconsolatazi4-Regular.otf and Inconsolatazi4-Bold.otf, the Inconsolata of
the LaTeX package `inconsolata`. It is the typewriter companion of the TeX
Gyre profiles (Palatino, Times, Bookman, Schoolbook, Euler) and of the
Palatino of macOS.
