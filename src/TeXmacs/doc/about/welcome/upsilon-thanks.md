# TeXmacs Upsilon: thanks

TeXmacs Upsilon is better for the people who tried it and told us what
broke, and for those who sent code. Thank you! The list is by first
contribution; the issues and pull requests are those of
[mgubi/texmacs](https://github.com/mgubi/texmacs). To be added, removed or
named differently, open an issue or say so in your report.

## Code

- **woutersj**: CMake for Qt 6 (#1), the Qt 5 build (#2), Qt's middle button
  (#3).
- **Joy Yang** (nerd-qp): the build under MSYS2 MinGW-w64 (#5).
- **Michelangelo Gubinelli** (minimagate): browser tabs and the warning
  before leaving with unsaved documents (#313), a more modern look for
  TeXmacs Vue (#314).

## Reports and testing

- **Yuan Fu** (casouri): building on macOS with MacPorts (#4).
- **woutersj**: slow wheel scrolling on Linux (#373), the file dialogs of
  Vue on Linux (#374), too much momentum in the browser (#375), the
  malformed question dialog on Linux (#376), the messages of a language
  server on hover and its balloons (#399), the language servers of Julia
  (#409).
- **Pierre-Henri Jondot** (phjo33): TeXmacs in the browser on an iPad
  without a keyboard (#377), the name proposed and the format of a document
  saved the first time (#400), the menus of macOS
  (#405).
- **hammerfunctor**: the build with GCC 16 (#378), plug-ins and
  `get-environment-variable` (#379).
- **Marc Mertens** (on the texmacs-users list): the builds with GCC and with
  Qt 5 (#389), symbols drawn as squares (#407), the times of a book of 2000
  pages (#408), and the slow search of formulas (#450).
- **medwatt**: Vue under Wayland and tiling window managers: the interface
  font, pasting in the fields, scrolling, dialogs (#391), the size of SVG icons (#394).
- **mlalaude**: the preferences of the AI sessions, and a session asked a
  question without an API key (#398).
- **amichail**: the icon bars at the right of the document (#404).
- **baudoly**: two windows on one document (#463, #464), the preferences
  with Inkscape installed (#465), dialogs with an accented title in Cocoa
  (#468), each with its cause found and a fix.
