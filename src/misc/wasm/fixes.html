TeXmacs Fixes

TeXmacs Fixes is the stock GNU TeXmacs (its development version, the SVN trunk) with bug fixes which are not yet in its releases: crashes, conversions to and from LaTeX, BibTeX, Windows paths, the Scheme bridge, editing modes and more. It adds nothing else: no new interface, no new features, the Guile 1.8 and the Qt 6 interface of the official TeXmacs. It is the conservative version, for those who want the fixes now; TeXmacs Upsilon is the bleeding-edge one.

Each fix is a pull request of the branch wip_fixes, made to be proposed to the official TeXmacs: the fixes in it. The builds below are made by the continuous integration of the repository from a state of that branch: they are tested, but they are not releases. Problems go to the issues of the repository, not to the official TeXmacs.

TeXmacs Fixes installs beside the stock TeXmacs and TeXmacs Upsilon, under its own name, and shares the preferences and the files of the user of the stock TeXmacs (~/.TeXmacs, on Windows %APPDATA%\TeXmacs): your styles, packages and plugins are there for both. They should not run at the same time, as each one writes the preferences it has when it quits.

All the files are those of the pre-release fixes-latest, whose label names the commit each one was built from.
